# 使用说明

## 启动与加载

Windows 发布包完整解压后，双击 `aindiff.exe`，保留同目录的 `_internal` 文件夹。
发布包内已包含运行环境和 alice。源码安装方式见 [README](../README.md)。

1. 点“打开左侧”选择 AIN；需要对照时再点“打开右侧”。选择文件后不会立即加载。
2. 为每侧选择“自动识别”或指定编码，点“加载 / 刷新”。
3. 只选一个文件也能编辑；若只选了右侧，成功加载后会连同编码移到左侧，使用“保存左侧”写回。

启动命令也可直接携带文件路径，路径含空格时使用引号：

```bash
python -m aindiff "单个.ain"
python -m aindiff "原版.ain" "汉化.ain"
```

加载失败会保留当前表格和未保存编辑；顶部路径框可能仍显示刚尝试的路径，保存确认中的路径才是本次实际写回目标。

文件读取、解析和对齐在后台执行，随后每批显示 300 行并更新进度。加载期间暂时禁用编辑、保存和再次加载，可移动窗口或退出；退出后不会应用后台读取结果。
主表仍保留全部数据，不是分页显示。大文件的内存需求、筛选和保存耗时仍与数据规模有关。

## 界面与快捷键

左右文件各有对应的保存按钮。文件栏下方提供“仅显示差异”“保存前备份 .bak”和“全部保存”；文本表底部显示编辑快捷键及颜色说明。

查找框内按 Enter 查找下一个，Shift+Enter 查找上一个。编辑框自动换行显示长文本，不会因此向保存内容插入换行；按 Enter 才插入实际换行。

窗口缩放或显示/隐藏结构栏时，左右文本列自动均分可用空间。若 F3 被 Snipaste 等软件占用，可使用查找按钮或 Enter／Shift+Enter，无需修改其他软件设置。

| 操作 | 入口或快捷键 |
| --- | --- |
| 打开左侧 / 右侧 | 顶部按钮，或 `Ctrl+O` / `Ctrl+Shift+O` |
| 加载 / 刷新 | 顶部同名按钮或 `F5` |
| 交换文件和编码 | “交换左右”，随后重新加载 |
| 打开查找框 | “查找（Ctrl+F）”或 `Ctrl+F` |
| 下一个匹配 | 查找框内回车、`F3` 或“下一个” |
| 上一个匹配 | 查找框内 `Shift+Enter`、`Shift+F3` 或“上一个” |
| 仅显示差异 | 文件栏下方开关，或菜单“视图 → 仅显示差异行” |
| 保存左侧 / 右侧 | 顶部按钮，或 `Ctrl+Shift+L` / `Ctrl+Shift+R` |
| 保存有修改的两侧 | “全部保存（Ctrl+S）”或 `Ctrl+S`，各侧分别确认 |
| 开关备份 | 文件栏下方“保存前备份 .bak”，或菜单“文件 → 写回前备份 .bak”，默认开启 |

主表中，相同文本通常为白色，不同文本为浅黄色，单边缺失为浅红色，有未保存编辑的行为浅绿色。
单文件模式不进行左右差异比较。

## 查找与筛选

输入任意文本片段、节名、类型 `s/m` 或 ID，然后回车定位。匹配两侧任意一侧即可命中；
搜索会归一化大小写、全角和半角字符，不会进行简繁转换或跨语言翻译。

超过一万行时，首次搜索和筛选分批计算并显示进度，完成后统一显示结果。扫描期间暂不能编辑、保存或重复发起查询，窗口仍可移动或退出；完成后可修改查询或继续查找。分批计算主要改善响应，不保证总耗时更短。
同一查询连续查找直接使用缓存，随后按该查询筛选也会复用匹配结果；修改文本后缓存自动失效。保存后的内部刷新和提交编辑时必要的筛选同步完成，保证后续操作顺序。

- “仅显示匹配”按当前查找内容筛选；同时启用“仅显示差异行”时，行必须满足两个条件。
- “清除”清空查找内容并关闭差异筛选，恢复全部行。
- 筛选时只保留含匹配行的节标题；没有匹配项时表格为空，清除筛选可恢复。
- “关闭”只收起查找栏，不清除筛选；菜单“显示全部行”只关闭差异筛选，仍保留文本查询。
- 查找定位可以重新显示被筛选隐藏的目标行；再次应用筛选后会重新按条件隐藏。
- 编辑后不再满足当前筛选条件的行及因此变空的节标题会立即隐藏，但编辑仍保留在内存中，可以保存。

## 结构导航与文本表

左侧“AIN 结构”默认显示二进制区段。需要函数级条目时，勾选结构栏标题旁的“文本节”，
或菜单“视图 → 左侧显示文本节（按函数）”。展开某个函数节后才生成该节子项。
选中子项可定位主表，点“编辑左侧 / 编辑右侧”即可编辑。

| 格式 | 可编辑区段 | 内容 |
| --- | --- | --- |
| System4 | MSG0 / MSG1 | 消息表 `m[]` |
| System4 | STR0 | 字符串表 `s[]` |
| xsys35 AINI/AIN2 | MSGI | 消息表 `m[]` |
| xsys35 AINI/AIN2 | VARI | 字符串表 `s[]` |

点击可编辑区段切换到原始表；CODE、FUNC 等其他区段只显示偏移和大小。
函数级视图中的文本按引用位置排列，同一 ID 可能多次出现；原始表按 ID 展示，行数可能不同。

点击切换的原始表超过 5 万条时会先询问。初次加载和自动回退不受此提示保护。
大文件建议按需展开，不要直接“展开全部结构”；本项目没有提供大文件界面流畅度保证。

## 编码与回退

日文原版通常选择 CP932，中文汉化通常选择 CP936/GBK，也可选择 UTF-8、BIG5、EUC-JP。
自动识别无法可靠区分同时可解码的字节序列，出现乱码时应手动选择后重新加载。

少数文件的函数名与正文编码不同，函数级读取可能失败。GUI 会尝试原始 MSG0/MSG1/STR0 表；
双文件模式要求两侧存在对应的文本表，可以对照 MSG0/MSG1 等不同消息表。**回退视图仅显示选中的表**，可通过结构栏切换其他可用表。
此时“文本节（按函数）”入口可能仍展示回退缓存，并不会恢复不可读取的函数信息。

GUI 中手动选择的编码在回退时仍然保留；无法用该编码解码时报告失败。
直接切换原始文本表及读取旧 AINI/AIN2 也使用严格解码；切换失败时保留原视图和未保存编辑。
CLI 的 `check` / `export` 仅在未指定编码时自动回退，显式编码读取失败直接报错。

v0.4.6 起，常规写回遇到 `iconv` 编码错误时会自动重试：修改文本仍严格使用所选编码，其他内容的原始字节保持不变，无需手动选择 Latin-1。
ランス０２的 MSG0（8066 条）和 STR0（937 条）均已通过副本抽样编辑、完整文本表比对、备份及恢复验证。函数级视图仍不可读取，请使用原始文本表。
这不代表所有混合编码文件均可保存，也尚未验证游戏内运行效果。不能用目标编码表示的文本会报错；失败时文件、已有备份和未保存编辑会保留。

## 编辑与保存

双击左侧或右侧文本单元格进入编辑：回车换行，`Ctrl+Enter` 或点击别处提交，`Esc` 取消。
提交只是更新内存，点保存并确认后才写入文件。`Ctrl+S` 会先提交正在编辑的单元格。

保存前请核对确认框中的完整路径。默认在原文件旁创建 `<原文件名>.bak`，例如 `game.ain.bak`；
**再次保存会覆盖已有同名备份**。若需要最初版本，请在首次编辑前另行复制文件。

System4 通过 alice 应用修改，旧 AINI/AIN2 由内置解析器写回。输出先写入独立临时文件，成功后替换原文件。
保存失败时未保存标记会保留，便于修改后重试。

同一 `s[id]` 或 `m[id]` 可能有多个引用位置：

- 修改一处并保存后，该 ID 在当前表格和缓存视图中的其他出现位置会同步更新。
- 若多处未保存编辑互相冲突，保存会被拒绝。将冲突编辑统一，或恢复为原文后再保存。
- 包含 NUL 的文本不能写回；无法用目标编码表示的字符也需更正或选择适用编码。

切换视图、刷新、交换左右或退出时，如有编辑会询问是否丢弃。
切换成功后已确认丢弃的编辑不会再次从缓存出现；目标读取失败会保留现有编辑。

## 命令行检查与导出

下面的命令用于源码安装后的终端环境：

```bash
python -m aindiff check "A.ain" "B.ain" --max-diffs 50
python -m aindiff export "A.ain" "B.ain" -o "compare.tsv"
python -m aindiff check --alice "vendor/alice/alice.exe" "A.ain" "B.ain"
```

`check` 正常完成时返回 0，即使发现差异；不能用它的退出码判断文本是否相同。
`export` 默认导出整个对照结果，不使用 GUI 中的编辑或筛选状态；自动回退时只导出提示的原始表。
输出不能与输入 AIN 指向同一文件。已有 TSV 会在成功导出后被替换，导出失败时保留旧结果。

TSV 使用带 BOM 的 UTF-8，可导入 Excel。列为
`no, section_left, section_right, type, id, occurrence, left, right, state`。
`type=SECTION` 为节标题；文本行的 `state` 为 `same`、`changed`、`left_only` 或 `right_only`。
正文含换行或制表符时会使用引号包围，不能简单按物理行数统计条目。

## 常见问题

### 找不到 alice 或程序打不开

Windows 版先确认完整解压，并保留 `_internal`。源码版先安装项目，再执行
`python -m aindiff fetch-alice`，或用 `--alice PATH`、`AINDIF_ALICE` 指定可执行文件。
运行时可查找用户缓存，发布构建则要求 `vendor/alice/alice.exe` 实际存在。

### 保存后游戏没有变化

确认保存的是游戏实际加载的文件，完全退出游戏后再启动。
旧存档中已经保存的内容可能不会随 AIN 改变；可从新游戏或修改文本出现之前的位置检查。

### 保存后文件大小变化

文本长度和容器重建可能使大小改变，大小本身不能证明保存结果正确。
可重新加载检查修改内容，并在游戏中验证；需要恢复时，先退出游戏和编辑器，再从备份复制回原路径。
