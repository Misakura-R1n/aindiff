【启动】
完整解压发布包后，双击 aindiff.exe，无需另装 Python 或 alice。
请保留同目录中的 _internal 文件夹，不要只复制 exe。

【打开文件】
1. 点“打开左侧”选择一个 AIN。
2. 需要对照时再选择右侧文件，建议使用同一游戏、同一版本的两个文本版本。
3. 为每侧选择编码，点“加载 / 刷新”。
只选右侧时，成功加载后会连同编码移到左侧，请使用“保存左侧”。

【编辑与保存】
双击文本单元格编辑，回车换行；Ctrl+Enter 或点击别处提交，Esc 取消。
提交后还需点“保存左侧 / 保存右侧”，或 Ctrl+S 保存有修改的两侧。
确认框会显示实际写回路径；保存前请核对它是否为游戏使用的文件。
浅黄色表示左右不同，浅红色表示单边缺失，浅绿色表示有未保存编辑。

默认备份为原文件旁的 <原文件名>.bak，再次保存会覆盖同名备份。
需要保留最初版本时，请另行复制。备份开关在“文件 → 写回前备份 .bak”。
同一 ID 的多个出现位置共用一个文本，保存后会同步；冲突编辑会被拒绝。
切换视图或刷新时，未保存编辑会询问是否丢弃；读取失败会保留现有编辑。

【查找与筛选】
Ctrl+F 打开查找框，回车或 F3 下一个；查找框内 Shift+F3 上一个。
“仅显示匹配”按查找内容筛选；差异筛选在“视图 → 仅显示差异行”。
两种筛选同时启用时，行必须同时满足条件。“清除”恢复全部行。
编辑后不符合筛选条件的行会隐藏，但修改仍可保存。

【结构与编码】
左侧默认显示 AIN 区段，点击文本区段切换到对应表：
  System4：MSG0 / MSG1 为消息表，STR0 为字符串表。
  旧 xsys35 AINI/AIN2：MSGI 为消息表，VARI 为字符串表。
勾选结构栏标题旁的“文本节”，可查看按函数归类的条目（文件支持时）。
大文件请按需展开；不建议使用“展开全部结构”。

日文原版通常选 CP932，中文汉化通常选 CP936/GBK。
自动识别不保证正确，乱码时请手动选择后重新加载。
混合编码文件可能回退到原始文本表，此时只显示选中的表。
手动编码在 GUI 回退时保持不变，无法解码则报告失败。
